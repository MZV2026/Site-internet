01 · Je découvre une notion

Un système qui détecte un mouvement

Dans un couloir, un éclairage peut s'allumer automatiquement lorsqu'une personne passe, puis s'éteindre lorsqu'il n'y a plus de mouvement détecté. Pour cela, le système utilise un capteur PIR.

La situation

Une lampe doit s'allumer lorsqu'une personne se déplace dans une zone, sans qu'elle ait besoin d'appuyer sur un interrupteur.

Problème : comment détecter un mouvement sans contact ?

Le mot PIR

PIR signifie Passive Infrared, c'est-à-dire infrarouge passif.

Le capteur détecte des variations du rayonnement infrarouge provenant des objets et des personnes dans son champ de détection.

Un exemple dans un bâtiment

Ce détecteur installé au plafond surveille une zone. Lorsqu'il détecte un mouvement, il peut commander automatiquement l'éclairage.

La lentille blanche diffuse permet au détecteur de surveiller une large zone.

Du mouvement à l'allumage de la lampe

Observe le décalage : la personne peut avoir quitté la zone alors que la sortie du capteur reste encore à HIGH.

Le signal HIGH est maintenu pendant un délai réglé sur le module. La lampe commandée par ce signal reste donc allumée après le départ de la personne.

02 · Je comprends le fonctionnement

Le capteur détecte-t-il une personne ?

Les êtres humains émettent naturellement un rayonnement infrarouge lié à leur chaleur. Le capteur PIR comporte un élément sensible qui réagit aux variations de ce rayonnement.

Quand une personne se déplace dans son champ de détection, le capteur peut détecter cette variation et produire un signal électrique.

À retenir : un capteur PIR détecte principalement un mouvement dans son champ. Il ne mesure pas la distance et ne reconnaît pas l'identité d'une personne.

Ce que le capteur perçoit

🧍
1. Une personne émet
Son corps chaud émet un rayonnement infrarouge invisible.
↓
〰️
2. Le rayonnement varie
Quand la personne se déplace, le rayonnement reçu par le capteur change.
↓
📟
3. Le capteur réagit
Il détecte cette variation et sa sortie passe à HIGH (1).

Le capteur ne « voit » pas une image : il réagit à une variation du rayonnement infrarouge reçu.

Une détection, pas une mesure de distance

SituationRéponse possible du capteur
Une personne traverse la zoneSignal HIGH (1) pendant un certain temps
Aucun mouvement détectéSignal LOW (0)
Une personne reste immobileLe capteur peut ne plus détecter de variation
Nature du capteur : le capteur PIR est un capteur tout ou rien (TOR), de type logique. Il ne fournit pas une valeur proportionnelle à la quantité de mouvement : sa sortie prend deux états possibles, LOW (0) ou HIGH (1).

05 · Je programme

Allumer une lampe lorsqu'un mouvement est détecté

Algorithme

Lire l'état du capteur PIR
↓
Un mouvement est-il détecté ?
↓
OUI : allumer la DEL
↓
NON : éteindre la DEL

Exemple de programme Arduino

Capteur PIR branché sur D2 et DEL sur D4.

#define PIR 2
#define LED 4

void setup() {
  pinMode(PIR, INPUT);
  pinMode(LED, OUTPUT);
}

void loop() {
  int mouvement = digitalRead(PIR);

  if (mouvement == HIGH) {
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }
}

Connecter le capteur réel à la carte Arduino

Schéma de câblage : le capteur PIR est connecté au port numérique D2 et le module DEL au port numérique D4.

Les deux modules se branchent sur les connecteurs Grove du Base Shield. Respecte les repères D2 et D4 imprimés sur la carte.

  • Brancher le câble Grove du capteur sur le port numérique D2 du Base Shield (connecteur marqué D2).
  • Le câble Grove assure les connexions VCC (alimentation), GND (masse) et SIG (signal).
  • La DEL témoin peut rester branchée sur la sortie D4 si tu souhaites également la piloter.

À retenir : dans ce montage, le signal du PIR arrive sur l'entrée numérique D2 de l'Arduino. Ne branche pas le capteur sur A2 : il fournit un état logique, pas une mesure analogique.

1. Téléverser ce programme

const int PIR = 2;
const int LED = 4;

void setup() {
  pinMode(PIR, INPUT);
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int etatPIR = digitalRead(PIR);
  digitalWrite(LED, etatPIR);
  Serial.println(etatPIR); // 0 = LOW, 1 = HIGH
  delay(100);
}

Dans l'IDE Arduino : sélectionner Arduino Uno et le bon port, téléverser le programme, puis fermer le Moniteur série avant la connexion depuis cette page.

07 · Je retiens l'essentiel

Ce qu'il faut mémoriser

  • PIR signifie infrarouge passif.
  • Le capteur détecte les variations du rayonnement infrarouge lorsqu'un corps chaud se déplace dans son champ.
  • Il fournit un signal numérique : HIGH (1) ou LOW (0).
  • Il ne mesure ni la distance ni l'identité d'une personne.
  • Il permet de commander automatiquement un éclairage ou une alarme.
