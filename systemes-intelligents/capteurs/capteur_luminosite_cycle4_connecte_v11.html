03 · Zoom — comprendre le capteur

Que se passe-t-il à l'intérieur ?

Représentation simplifiée d'un capteur photosensible
  1. La lumière arrive sur l'élément photosensible.
  2. L'élément réagit à la quantité de lumière reçue : une caractéristique électrique varie.
  3. Le circuit électronique transforme cette variation en un signal exploitable.
  4. Le système acquiert une valeur qui pourra être traitée par un programme.
Dans une photorésistance (LDR), la lumière reçue fait varier la résistance électrique du matériau photosensible. Cette variation peut ensuite être convertie par le circuit électronique en une tension, puis en une donnée numérique lue par le système.

04 · Je programme

Déclencher une action si la luminosité est faible

On choisit un seuil. Lorsque l'indice associé à la mesure dépasse le seuil choisi (ce qui correspond ici à une faible luminosité), le système allume une DEL rouge et déclenche une alarme sonore. Sinon, les deux sorties restent inactives.

Mode matériel · Arduino + Grove

Mesurer la luminosité avec le capteur réel

Connecte l'Arduino Uno au port USB. Le capteur de luminosité Grove doit être branché sur l'entrée A0 du Grove Base Shield.

1. Téléverser ce programme dans l'Arduino

const int capteur = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int mesure = analogRead(capteur);
  Serial.println(mesure);
  delay(100);
}

Dans l'IDE Arduino : choisir la carte et le port, téléverser le programme, puis fermer le Moniteur série.

06 · Synthèse

Ce que je dois retenir

  • Un capteur acquiert une information sur une grandeur physique de l'environnement.
  • Une photorésistance voit sa résistance diminuer lorsque la lumière reçue augmente. Le circuit associé transforme cette variation en un signal exploitable par le système.
  • La valeur fournie dépend de la technologie du capteur et de son électronique ; elle n'est pas toujours exprimée en lux.
  • Le programme traite la valeur et peut commander un ou plusieurs actionneurs.
  • Une condition permet de déclencher une action lorsque la valeur franchit un seuil.
Vocabulaire

Grandeur physique : caractéristique mesurable d'un phénomène, par exemple la température, la distance ou la luminosité.

Capteur : composant qui acquiert une grandeur physique et la convertit en signal exploitable.

Seuil : valeur de référence utilisée pour déclencher une action.

Actionneur : composant qui réalise une action sur l'environnement : produire de la lumière, un son, un mouvement…
